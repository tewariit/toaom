# โตออม

สมุดปลดหนี้ ทันเกษียณ — แอปการเงินส่วนตัว (ปลดหนี้ งบค่าครองชีพ เป้าออม คาดการณ์เกษียณ โค้ช AI)

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้า "ประตู" ที่มีไอคอน กดแล้วพาไปตัวแอปจริงใน claude.ai (`#setup` = หน้าติดตั้งไอคอน) |
| `manifest.webmanifest`, `apple-touch-icon.png`, `favicon.png`, `icons/` | ไอคอนและข้อมูลสำหรับเพิ่มไปหน้าจอโฮม |
| `app-source/toaom.html` | สำเนาซอร์สของตัวแอป (เวอร์ชันที่เผยแพร่ใน claude.ai) สำหรับสำรองและดูประวัติ |

## ตัวแอปจริงอยู่ที่ไหน

- แอปเผยแพร่เป็น Artifact ใน claude.ai: https://claude.ai/artifact/XSSdBvJTo651SxgK6utSf6
- ข้อมูล (หนี้ งบ รายการ ประวัติ AI) เก็บในบัญชี Claude ของเจ้าของ แยกเป็นส่วนตัว **ไม่อยู่ใน repo นี้**
- โค้ช AI และการซิงก์ข้อมูลทำงานเฉพาะเมื่อเปิดผ่าน claude.ai

## วิธีอัปเดต

1. คุยกับ Claude ให้แก้แอป แล้วเผยแพร่ทับลิงก์เดิมใน claude.ai — ไอคอนจะเปิดเวอร์ชันใหม่ทันที
2. อัปเดตไฟล์ `app-source/toaom.html` ใน repo นี้ให้ตรงกับเวอร์ชันล่าสุด (เพื่อสำรอง)
3. ถ้าลิงก์ Artifact เปลี่ยน ให้แก้ตัวแปร `APP` ใน `index.html`

> หมายเหตุ: `app-source/toaom.html` เป็นเนื้อหาส่วน body ที่ claude.ai ห่อด้วย `<!doctype html>` ตอนเผยแพร่ ถ้าเปิดไฟล์นี้ตรงๆ จะทำงานแบบเก็บข้อมูลในเบราว์เซอร์เครื่องนั้นเท่านั้น และไม่มีโค้ช AI
