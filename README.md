# โตไลฟ์

สุขภาพกับเงิน ในแอปเดียว — รวม **ฟิต** (ลดน้ำหนัก วิ่ง อาหาร) กับ **ออม** (รายจ่าย ปลดหนี้ เป้าออม เกษียณ) พร้อมหน้าภาพรวม โค้ช AI ทุกหน้า และแถบเลือกวันที่ร่วมกัน

## ตัวแอปจริงอยู่ที่ไหน

- แอปเผยแพร่เป็น Artifact ใน claude.ai: https://claude.ai/artifact/6gVs9q9WEkqAPrzo1NSada
- ข้อมูล (น้ำหนัก การวิ่ง มื้ออาหาร รายจ่าย หนี้) เก็บในบัญชี Claude ของเจ้าของ **ไม่อยู่ใน repo นี้**
- โค้ช AI และการซิงก์ข้อมูลทำงานเฉพาะเมื่อเปิดผ่าน claude.ai ใช้โควตาของบัญชี Claude ไม่ต้องมี API key

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้า "ประตู" มีไอคอน เปิดแล้วพาไปตัวแอปใน claude.ai (`#setup` = หน้าติดตั้งไอคอน) |
| `manifest.webmanifest`, `apple-touch-icon.png`, `favicon.png`, `icons/` | ไอคอนสำหรับหน้าจอโฮม |
| `app-source/toalife.html` | ซอร์สของแอปเวอร์ชันที่เผยแพร่ล่าสุด (ส่วน body ที่ claude.ai ห่อด้วย `<!doctype html>`) |
| `app-source/build/` | ชุดประกอบร่าง: `orig/` คือโตฟิตกับโตออมต้นฉบับ, `shell.html` คือแถบบน หน้าภาพรวม โค้ช AI แถบวันที่, `patches.py` คือส่วนที่แก้ทับโค้ดเดิม (ราคามื้อไปออม ยอดเหลือใช้วันนี้ วันที่ร่วม), `build.py` รวมทั้งหมดเป็น `toalife.html` |

## วิธีอัปเดต

1. คุยกับ Claude ให้แก้แอป แล้วเผยแพร่ทับลิงก์เดิมใน claude.ai — ไอคอนเปิดเวอร์ชันใหม่ทันที
2. อัปเดตไฟล์ใน `app-source/` ให้ตรงกับเวอร์ชันล่าสุด แล้ว `python3 app-source/build/build.py` ต้องได้ไฟล์ตรงกับที่เผยแพร่
3. ถ้าลิงก์ Artifact เปลี่ยน ให้แก้ตัวแปร `APP` ใน `index.html`

## ติดตั้งไอคอน

เปิด `https://tewariit.github.io/toaom/#setup` ใน Safari แล้วทำตามขั้นตอนบนหน้า

> repo นี้ชื่อ toaom เพราะเดิมเป็นของโตออม (ลบแล้ว รวมเข้าโตไลฟ์ 1 พ.ย. 2569) ไอคอนโตออมเดิมบนหน้าจอโฮมจะพามาโตไลฟ์อัตโนมัติ
